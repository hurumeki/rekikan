# れきかん — アプリコンセプトドキュメント

**バージョン:** v1.0  

---

## 1. プロダクト概要

### 1.1 プロダクト名

「れきかん」（Rekikan — 歴史の感覚をつかむ）

### 1.2 コンセプト

歴史のカードを「古い順」に並べ替えるパズルゲーム。大きな時代区分から始めて、段階的に細かい区切りへと進むことで、歴史の流れを自然に理解できる学習アプリ。

### 1.3 背景と課題認識

歴史学習には以下の課題がある。

- 個別の事件や年号の暗記から始めるアプローチは、初学者にとってハードルが高く、全体像の把握が難しい
- 既存の歴史カードゲーム（年号順に並べるタイプ）は、ある程度の知識がある人向けであり、子どもや初学者には難易度が高い
- 地域・年代ごとに「だいたいの流れ」をつかんでから詳細に進むほうが、知識の定着がしやすい
- 御成敗式目と武家諸法度のように、時代が異なるのに混同されやすい用語が多い。用語を覚える際に「どんなカテゴリの知識か」が曖昧なまま暗記してしまうことが原因の一つである

### 1.4 解決アプローチ

**「大→小」のズームイン学習を、階層構造で実現する。**

- まず用語に頼らず「時代の雰囲気」を説明文で並べ替え、流れのイメージをつかむ
- 次に時代名・用語のカードで段階的に細かい区切りへ進む
- カードに地域・時代帯・種類の視覚タグをつけ、「これはどんなカテゴリの知識か」を直感的に認識できるようにする
- 大きい区分をクリアすると細かい区分がアンロックされる仕組みで、学習順序をガイドしつつ先に進む動機づけを行う

### 1.5 ターゲットユーザー

幅広い層に対応する。

- 小学校高学年〜中学生（歴史の授業の予習・復習）
- 高校生（受験対策の基礎固め）
- 大人の学び直し（教養として歴史を整理したい人）

## 3. カード設計

### 3.1 カードの種類

2種類のカードを用意する。

| 種類 | 内容 | 用途 |
|------|------|------|
| **説明文カード** | 用語を使わず、時代の特徴を2〜3行で記述 | 全階層で使用可能。用語知識がなくても時代の変化のイメージをつかめる |
| **用語カード** | 時代名・人名・出来事名＋ヒント＋解説 | 全階層で使用。知識の定着に使う |

説明文カードは入門（大区分の前）だけでなく、中区分・小区分に対しても作成する。用語カードで学ぶ前に、説明文カードで「時代の変化のイメージ」をつかむステップを各階層に設けることで、どの段階でも「雰囲気→用語」の順序で学べるようにする。

**説明文カードの例：**

大区分の入門（日本の歴史の大きな流れ）：
- 「狩りや採集で暮らし、土器を使って煮炊きしていた非常に長い時代」
- 「大陸から稲作が伝わり、人々が定住してムラを作り始めた時代」
- 「貴族が優雅な暮らしの中で独自の文字や文学を生み出した時代」

中区分（江戸時代の変化）：
- 「戦乱が終わり、新しい幕府が全国を統一した。外国との交流を制限し始めた時代」（初期）
- 「幕府の力が安定し、華やかな町人の芸術や文学が生まれた」（前期・元禄）
- 「財政が苦しくなり、幕府が何度も改革を試みた時代」（中期）
- 「外国船が現れ始め、国内でも不満や改革の動きが広がった」（後期）
- 「外国の圧力で開国し、幕府が倒れるまでの激動の時代」（幕末）

説明文には年号や固有名詞を極力入れず、「雰囲気」で判断できる書き方にする。

### 3.2 用語カードの構成要素

| 要素 | 表示タイミング | 説明 |
|------|--------------|------|
| 用語名 | 常時 | 時代名・人名・出来事名 |
| 視覚タグ | 常時 | 時代帯の色＋種類アイコン（後述） |
| ヒント | 解答前（ON/OFF切替可能） | キーワード形式の手がかり |
| 年代 | 答え合わせ後 | 正解の年代表示 |
| 一言解説 | 答え合わせ後 | 「この時代はこんな時代」を1〜2文で説明 |

### 3.3 視覚タグの設計

カードに2軸の視覚情報を付与し、「どのカテゴリの知識か」を直感的に認識できるようにする。

**軸1：時代帯カラー**
カードの左端にカラーバーを表示。時代帯ごとに色を割り当てる。

| 時代帯（日本史の例） | 色 |
|--------------------|----|
| 先史・古代（縄文〜平安） | 緑系 |
| 中世・近世（鎌倉〜江戸） | 藍系 |
| 近代・現代（明治〜昭和） | 赤系 |

同じ時代帯のカードは同じ色なので、「御成敗式目（藍）と武家諸法度（藍）は同じ時代帯だが、鎌倉時代と江戸時代で位置が離れている」ことが視覚的に分かる。異なる時代帯であれば色が違うため、混同を防ぎやすい。

**軸2：種類アイコン**
カード上に小さなアイコンを表示。初期は5〜6種に絞る。

| 種類 | アイコン例 | 含まれるもの |
|------|----------|------------|
| 政治・法 | ⚖️ | 法律、制度、政治改革 |
| 戦・外交 | ⚔️ | 戦争、条約、外交事件 |
| 文化・宗教 | 🎨 | 文学、芸術、宗教、思想 |
| 経済・技術 | 💰 | 経済政策、技術革新、産業 |
| 人物 | 👤 | 特定の人物が主題のカード |

種類を細かくしすぎると分類自体が学習コストになるため、大分類に留める。

## 4. 階層構造とアンロック方式

### 4.1 設計思想

問題を階層構造（ツリー）で管理し、上位の問題をクリアすると下位の問題がアンロックされる仕組みにする。学習の順序を自然にガイドしつつ、「次が開く」ゲーム的な動機づけを行う。

### 4.2 階層の具体例（日本史）

```
日本史
├── [入門] 説明文で並べる：日本の歴史の流れ（5〜6枚）
│   ├── [Lv.1] 先史・古代（縄文〜平安）（6〜7枚）
│   ├── [Lv.1] 中世・近世（鎌倉〜江戸）（5〜6枚）
│   ├── [Lv.1] 近代・現代（明治〜昭和）（5〜6枚）
│   └── [通し] 全時代区分（14枚）  ※上記3つクリアで開放
│       ├── [Lv.2] 江戸時代の将軍（7枚 × 前半/後半）
│       │   └── [Lv.3] 江戸時代の出来事
│       ├── [Lv.2] 幕末〜明治の出来事（7枚）
│       └── ...
└── [横断] 日本×世界 同時代パズル  ※複数地域のLv.1クリアで開放
```

### 4.3 1問あたりのカード枚数

**原則7枚前後（5〜8枚）に収める。**

- スマホの1画面にスクロールなしで収まる
- 認知心理学のマジックナンバー7±2と合致し、初学者が挫折しにくい
- 日本の時代区分（14枚）のような多いものは、分割してから「通し」で解く構成にする

**通し問題（10枚以上）の位置づけ：** 分割ステージをクリアした後の「まとめテスト」として配置する。既に各ブロックを学習済みなので、枚数が多くてもユーザーの心構えが違い許容範囲となる。

### 4.4 アンロックのルール

- 初期状態では各地域の「入門（説明文カード）」のみプレイ可能
- 入門クリアで、その地域のLv.1（分割ステージ）が開放
- 分割ステージを全てクリアすると「通し」が開放
- 通しクリアでLv.2以降が開放
- 複数地域のLv.1クリアで「横断問題」が開放

**救済策：** 同じステージに一定回数（例：3回）挑戦するか、ヒントONでクリアした場合も次を開放する。途中で詰まって先に進めないストレスを防ぐ。

## 5. ゲームモード

### 5.1 モード構成

2つのモードを用意する。学習体験として明確に差別化された2モードとする。

| モード名 | 操作 | 対象ユーザー |
|----------|------|------------|
| **じっくりモード** | 「1番古いのはどれ？」を繰り返し選択 | 初学者。確実に考えながら進む |
| **チャレンジモード** | 全カードを並べてから一括判定 | 慣れた人。スピード感がある |

### 5.2 じっくりモード

「残りの中で1番古いのはどれ？」という問いに、カードをタップして回答する方式。

- 残りカードの中から1枚選ぶだけなので操作がシンプル
- 毎回能動的な判断を求められるため学習効果が高い
- 正解するとそのカードが上部の「確定エリア」に並んでいく
- 不正解の場合、正解のカードがハイライトされ、一言解説が表示される

### 5.3 チャレンジモード

全カードを自分の考える順番に並べてから、一括で答え合わせする方式。操作は「順番タップ方式」（後述）を採用する。

---

## 6. 操作設計

### 6.1 基本操作：順番タップ方式（チャレンジモード）

「順番にタップして並べ替える」方式を採用する。

**操作フロー：**

1. シャッフルされたカードが表示される
2. 「1番目に古い」と思うカードをタップ → カードに ① のバッジがつく
3. 「2番目に古い」と思うカードをタップ → ② がつく
4. 以下繰り返し
5. 画面上部に「この順番で確定する」ボタンが表示される
6. ボタン押下で、選択した順番にカードが並び替わり固定される

**キャンセル操作：** 選択済みのカードをもう一度タップすると選択が解除され、以降の番号が詰まる（例：①②③の②を解除すると、③が②に繰り上がる）。

**カードの固定：** 自信のあるカードを長押しで固定/解除できる。固定されたカードは鍵アイコンが表示され、位置が変わらない。「この2枚は確実」というときにロックしておき、残りだけ考えることができる。

### 6.2 じっくりモードの操作

残りカードの中から1枚タップするだけ。追加の操作説明は不要で、直感的に使える。

### 6.3 カードの視覚状態

| 状態 | 表示 |
|------|------|
| 未選択 | グレー系の通常表示 |
| 選択済み | アクセントカラー＋番号バッジ（①②③…） |
| 固定済み | 別色＋鍵アイコン |
| 正解（答え合わせ後） | 緑＋✓ |
| 不正解（答え合わせ後） | 赤＋✗ |

## 7. フィードバック設計

### 7.1 答え合わせ後の表示

両モード共通で、答え合わせ後に以下を表示する。

- 各カードの正誤マーク（✓ / ✗）
- 正解の年代
- 一言解説（「この時代はこんな時代」）
- スコア（○ / ○ 正解）
- 全問正解時は「パーフェクト！」演出

### 7.2 じっくりモード固有のフィードバック

- 正解時：カードが確定エリアに移動し、年代と解説が表示される
- 不正解時：正解カードがハイライトされ、解説が表示される。不正解のカードは選択肢に残る

## 8. 追加機能（今後実装）

### 8.1 日本史と世界史の横断問題

同時代に異なる地域で起きた出来事を混ぜて出題するモード。

- 例：「鎌倉時代」「十字軍の時代」「宋」を同時に出題し、地域横断で年代順に並べる
- 日本と世界の同時代性を体感的に理解できる
- 開放条件：複数地域のLv.1をクリア

### 8.2 苦手な時代を重点出題

正答率をカード単位で記録し、間違えやすいカードや時代を優先的に出題する。

- カードごとの正答率・回答回数を端末に保存
- 正答率が低いカードが含まれるステージを「おすすめ」として表示
- 復習モード：苦手カードだけを集めたカスタムステージを自動生成

### 8.3 その他の拡張候補

- タイムライン表示：答え合わせ後に、正解の並びをタイムライン図として可視化
- 実績・バッジ：特定の条件（パーフェクト、連続正解など）で獲得
- 出題カスタマイズ：ユーザーが自分でカードセットを作成・共有できる機能

## 9. UI/UXの方針

### 9.1 デザインの方向性

#### 9.1.1 コンセプトから導かれるデザイン原則

デザインは「見た目の好み」ではなく、アプリのコンセプトと学習体験から導く。以下の要件を満たす必要がある。

**原則1：幅広い年齢層に対応する**
ターゲットが小学生〜大人と広いため、特定の年齢層だけに刺さるトーンは避ける。子どもにとっつきやすく、大人にも安っぽく見えない「年齢を選ばない」トーンが必要。ライト/ダークのテーマ切替を提供し、デフォルトはライトテーマとする（学習アプリとしての可読性・安心感を優先）。

**原則2：視覚タグが機能として成立する**
時代帯カラーと種類アイコンは装飾ではなく「カテゴリの直感的認識」という学習機能を担う。どのテーマ（ライト/ダーク）でも視認性を保てる配色設計が必須。背景色に埋もれない十分なコントラストを確保する。

**原則3：カードの5つの状態が明確に区別できる**
未選択・選択済み・固定済み・正解・不正解の5状態を色で表現する。ベースはニュートラルに抑え、状態変化に色のバリエーションを割り当てる。

**原則4：説明文カードの可読性**
説明文カードは2〜3行のテキストが主役なので、フォントサイズ・行間・コントラストを十分に確保する。用語カードとの視覚的な区別も必要（カードの形状やラベル表示で区別）。

**原則5：操作の分かりやすさが最優先**
装飾よりもタップ領域の大きさ、状態変化のフィードバックの明快さを重視する。

#### 9.1.2 世界観：「地層を掘り下げる」

「れきかん」の学習体験は、歴史という地層を大きな層（時代区分）から順に掘り下げていく行為に重なる。この「地層」のメタファーをデザインの世界観として反映する。

**階層ごとの地層表現**
ステージ選択画面（ホーム画面）で、階層の深さを地層のように視覚的に表現する。上層（大区分）は明るく広い地層、下層（中区分・小区分）に進むほど色が深く・濃くなっていく。アンロックされていないステージは「まだ掘れていない地層」として暗く表示し、クリア済みは掘り起こされて中身が見えている状態として表現する。

**掘り進める感覚の演出**
ステージクリア後に次の階層がアンロックされる際、地層がひとつ掘れる（開く）ようなアニメーションで、「深く進んでいる」実感を与える。

**時代帯カラーと地層の対応**
時代帯カラー（先史・古代=緑系、中世=藍系、近世=紫系、近代=橙系、現代=赤系）は、地層の色合いとしても機能する。ステージ選択画面で縦に並んだ時代帯が、そのまま地層の断面図のように見える構成にする。

**控えめな適用**
世界観の反映はステージ選択画面と画面遷移の演出に集中させる。クイズ画面はカードの可読性と操作性が最優先のため、世界観の演出は背景のさりげない色調程度に留め、学習の邪魔にならないようにする。

#### 9.1.3 カラー設計

**テーマ対応**
ライト/ダークの切替を前提とし、CSSカスタムプロパティ（変数）で管理する。全ての配色をライト/ダーク両方で定義する。

**地域カラー（アクセント）**

| 地域 | カラー | 用途 |
|------|--------|------|
| 日本史 | 赤系 | ヘッダー、ステージ枠線、バッジ |
| ヨーロッパ史 | 青系 | 同上 |
| 中国史 | 金系 | 同上 |

**時代帯カラー（視覚タグ）**

各地域で5段階程度の色を定義する。ライト/ダーク両テーマで十分なコントラストを確保する。

| 時代帯 | ライトテーマ | ダークテーマ |
|--------|------------|------------|
| 先史・古代 | 緑系（中明度） | 緑系（やや明るめ） |
| 中世 | 藍系（中明度） | 藍系（やや明るめ） |
| 近世 | 紫系（中明度） | 紫系（やや明るめ） |
| 近代 | 橙系（中明度） | 橙系（やや明るめ） |
| 現代 | 赤系（中明度） | 赤系（やや明るめ） |

**状態カラー**

| 状態 | 色 | 備考 |
|------|-----|------|
| 未選択 | ニュートラル（グレー系） | ベース状態 |
| 選択済み | ブルー系 | 地域カラーと混同しないよう注意 |
| 固定済み | ティール系＋鍵アイコン | 選択済みと明確に区別 |
| 正解 | グリーン | ユニバーサルな「正解」の色 |
| 不正解 | レッド | ユニバーサルな「不正解」の色 |

#### 9.1.4 今後の検討事項

- 具体的な配色のコントラスト比検証（WCAG AA基準）
- 地層メタファーのステージ選択画面のプロトタイプ作成
- 色覚多様性への対応（色だけでなくアイコン・形状でも状態を区別）
- アニメーション（地層が開く演出）のパフォーマンス検証

### 9.2 画面構成

| 画面 | 内容 |
|------|------|
| ホーム画面 | 地域選択 → 階層ツリーの表示。アンロック状態が分かるマップ的UI |

### 9.3 レスポンシブ対応

### 10.1 アプリ構成

## 付録：学習設計の原則

本アプリの学習設計は、以下の原則に基づいている。

**「大→小」のズームイン学習：** 認知科学でいう「スキーマ構築」のアプローチ。まず大枠のフレームワークを頭に入れ、そこに詳細を紐づけていくことで、バラバラの知識ではなく構造化された理解が得られる。

**説明文ファーストの導入：** 用語や年号の前に、時代の「雰囲気」や「変化のイメージ」を体感する。用語知識ゼロでも取り組めるため、初学者の入り口として機能する。

**並べ替えによる体感：** 年号を暗記するのではなく、「だいたいこの辺」という時代感覚を身体的に獲得する。正確な年号を知らなくても、順番の感覚があれば歴史の因果関係を理解する土台になる。

**視覚タグによるカテゴリ認識：** 用語を覚える際に「これはどんなカテゴリの知識か」を視覚的に紐づける。混同されやすい用語の区別を助け、記憶の整理に貢献する。

**ヒントによる足場かけ：** 初学者はヒントONで取り組み、慣れてきたらOFFにする。同じステージでも難易度を自分で調整でき、繰り返し学習のモチベーションを維持しやすい。

**横断学習による多角的理解：** 日本史と世界史を横断することで、「鎌倉時代のころヨーロッパでは十字軍だった」のような同時代性の感覚が身につき、一国史の枠を超えた歴史理解につながる。
