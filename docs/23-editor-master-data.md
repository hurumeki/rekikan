> Source: `rekikan-editor-design.md` — Sections 5.1–5.3

---

## 5.1 Regions (regions)

| Operation | Description |
|-----------|-------------|
| List | Display ID, label, emoji, color, and sort order in a table |
| Edit | Inline editing or modal |
| Add | Add a new region |
| Delete | Show a warning if cards or stages are linked to the region |

---

## 5.2 Era Bands (era_bands)

Displayed grouped by region. Each era band's color is shown as a preview.

---

## 5.3 Categories (categories)

A list of icons and labels. Shared across all regions.
