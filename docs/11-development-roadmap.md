# Development Roadmap

> Source: `rekikan-concept.md` — Section 11

---

## Phase 1: MVP (Minimum Viable Product)

The minimum configuration to realize the core experience.

- Implement Careful Mode and Challenge Mode
- Tap-to-order interaction
- Display description cards and term cards
- Hint display (ON/OFF toggle)
- Post-answer date and one-line explanation display
- Broad-division stages for Japanese History, European History, and Chinese History

## Phase 2: Hierarchy and Visual Tags

Implement learning progression and visual information organization.

- Hierarchical structure and unlock system
- Add medium- and fine-division stages
- Implement visual tags (era band colors + category icons)
- Strata design for the stage selection screen
- Light/dark theme switching

## Phase 3: Learning Support and Cross-Region Features

Add features to enhance learning effectiveness.

- Save learning history
- Focused drilling on weak areas
- Japan × World History cross-region quizzes
- Timeline visualization (after answer checking)

## Phase 4: Expansion

- Add more regions (American History, Middle Eastern History, Southeast Asian History, etc.)
- Achievements / Badges
- Custom quiz creation (user-created and shared card sets)
